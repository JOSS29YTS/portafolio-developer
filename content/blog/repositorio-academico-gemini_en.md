## Academic Repository: Document Management with Gemini AI

I developed a premium digital systems ecosystem for **Nuestra Señora de Fátima School**, automating the preservation and intelligent analysis of scientific research projects for high school seniors.

### Architecture

A modern SPA with secure Role-Based Access Control (RBAC) for Directors and Teachers, an immutable system audit module, automatic synchronization with Google Drive for disaster recovery, and a real-time interactive PDF viewer.

### Gemini AI Integration

The most exciting component was integrating the **Google Gemini 2.0 Flash SDK** for:

- **Automated parsing** of complex PDF documents.
- **Intelligent structuring** of academic metadata.
- **Optimized caching** using MySQL as the primary database storage layer.

### System Modules

| Module | Description |
|--------|-------------|
| Dashboard | Academic metrics with reactive SVG charts |
| Projects | Upload, review, and approval of research works |
| Search | Full-text search with advanced filtering |
| Users | RBAC user management and permissions |
| Auditing | Immutable logs for all system operations |
| Configuration | Custom system settings per institution |

### Security

I implemented strict Role-Based Access Control (RBAC), an immutable audit log system for school safety, and created analytical visualizations with pure SVG charts to guarantee a premium and fluid user experience with React 19.

The live deployment is available on [Vercel](https://servicio-comunitario-portafolio.vercel.app/) and the code is open source on [GitHub](https://github.com/JOSS29YTS/servicio_comunitario_portafolio).
